# Write a Proposal Section

Draft a specific proposal section optimized for the highest evaluation rating.

## Workflow

1. Identify which section to write — the user specifies (e.g., "technical approach for Task Area 2", "management volume", "executive summary")
2. Read the solicitation analysis (`analysis.md`) for requirements and evaluation criteria for this section
3. Read the capture plan (`capture-plan.md`) for win themes and discriminators
4. Search `~/TenderB/projects/` for relevant past proposal content from similar bids
5. Search `~/TenderB/templates/` for reusable boilerplate and templates
6. Write the section following golden rules:
   - Answer exactly what Section L asks
   - Lead with the answer — first sentence is your solution
   - Feature → Benefit → Proof for every claim
   - Mirror SOW/PWS terminology exactly
   - Address every subfactor in order
   - Measurable commitments with specific numbers
   - Weave win themes throughout
7. Self-check: Would this score "Outstanding" against Section M criteria?
8. Verify within page limit, correct format
9. Save to `~/TenderB/projects/{name}/sections/{section-name}.md`

## If Missing Context

If analysis.md or capture-plan.md don't exist, ask the user for the key information needed: What are the evaluation criteria? What are the win themes? What's the page limit?
